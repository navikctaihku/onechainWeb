Open API Platform Product overview

Base URL & auth

https://api.one-chain.io
Authorization: Bearer <api_key>

Create a free account → generate an API key in the dashboard → send it on every request.

# Example
curl -X GET "https://api.one-chain.io/api/v2/docs/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
